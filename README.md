One sentence, no more than 200 characters, pitching a startup idea so strange it sounds like a joke, yet specific enough that a reader can see the customers and the money.

> GoatCrew rents out trained goats at $49 a day: homeowners skip the mower, the goats eat the weeds and fertilise the lawn, and 200 goats book out every weekend at half a landscaper's price.

## Run

```sh
python3 main.py
```

`main.py` gates the sentence (one sentence, 1–200 chars, not whitespace-only), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), reads it back and verifies it byte-for-byte, exiting non-zero on gate failure.
